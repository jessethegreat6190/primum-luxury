# Primum & Luxury Hotel

A hotel reservation website for **Primum & Luxury**, featuring gallery, rooms, booking, and contact pages.

## Pages
- `index.html` — Home
- `explore.html` — Facilities / gallery
- `rooms.html` — Rooms
- `bb.html` — Booking
- `contact.html` — Contact

## Tech
- HTML5
- CSS3
- jQuery / Slick (slider)

## Local preview
Serve the folder from any static web server (e.g. Apache/XAMPP) and open `index.html`.
